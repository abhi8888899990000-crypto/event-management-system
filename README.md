
# 🎟️ AI-Powered Smart Event Management and Analytics System

An AI-powered web-based Event Management and Analytics System that helps organizers manage events, registrations, ticket bookings, attendance, and feedback while using Machine Learning and Statistical Analysis to predict event attendance, estimate ticket demand, and provide personalized event recommendations.

## 📌 Overview

Traditional event management systems mainly focus on event creation, registration, and ticket booking. They often do not provide data-driven insights into expected attendance or ticket demand.

This project combines:

- Event Management
- Ticket Booking
- Attendance Tracking
- Machine Learning
- Statistical Analysis
- Event Recommendation
- Data Visualization
- QR-Based Check-in
- REST API
- SQL Database

The system analyzes historical event data such as category, ticket price, registrations, attendance, cancellations, revenue, and user interactions to generate useful predictions and recommendations.

## 🎯 Objectives

The main objectives of this project are:

1. Build a complete event management system.
2. Allow organizers to create, update, and manage events.
3. Allow users to discover and register for events.
4. Provide ticket booking and booking management.
5. Predict event attendance using Machine Learning.
6. Predict ticket demand for upcoming events.
7. Develop a personalized event recommendation system.
8. Compare different Machine Learning models.
9. Perform descriptive statistics and correlation analysis.
10. Estimate attendance and high-demand event probabilities.
11. Build an interactive analytics dashboard.
12. Implement QR-based ticketing and event check-in.
13. Follow Software Engineering practices including UML, testing, and documentation.

### 📊 Statistical Analysis

The system performs:

The dashboard provides visual insights into:

## 🧠 Machine Learning Models

The project proposal includes the following Machine Learning algorithms:

| Algorithm | Possible Application |
|---|---|
| Logistic Regression | Attendance / demand classification |

### 📏 Evaluation Metrics

Depending on the ML task, the system can use:

- Accuracy
- Precision
- Recall
- F1 Score
